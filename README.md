## Problem statement
Telecom providers lose revenue when customers discontinue their subscriptions. This case study explores customer and service attributes, visualizes patterns associated with churn, and builds a Multilayer Perceptron (MLP) classifier to estimate churn risk.

## Dataset
The script downloads the public IBM Telco Customer Churn sample dataset:
https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv

The dataset contains customer demographics, account information, subscribed services, billing attributes, and the `Churn` target. `customerID` is excluded from model training because it is an identifier. `TotalCharges` is converted to numeric and blank values are treated as missing. Run the script to print the exact row/column count and missing-value summary for the downloaded file.

## Assignment requirements covered
- Real-world dataset with more than 15 fields.
- Missing-value handling, duplicate checks, type conversion, categorical encoding and numeric standardization.
- EDA: class distribution, tenure histogram, monthly-charge boxplot, contract/churn chart, correlation heatmap and internet-service/churn chart.
- Train/validation/test split.
- Deep learning model: MLP classifier with a small comparison of hidden-layer sizes and regularization.
- Evaluation: accuracy, precision, recall, F1, ROC-AUC, confusion matrix, ROC curve, error distribution and loss curve.
- Report and code appendix.
